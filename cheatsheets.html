pathlib Module

Import with from pathlib import Path — a modern, cross-platform way to work with file paths. Path objects use / to build paths and work correctly on Windows, Mac, and Linux.

A note on capitalization: Path (capital P) is the class — the blueprint you import. path (lowercase p) in the table below is just a placeholder for whatever variable you've stored a Path object in — you could call it p, my_file, or anything else. For example: p = Path('/home/jovyan/data.csv') then p.name. Class names in Python are capitalized by convention; variable names are not.
