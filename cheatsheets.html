NumPy

Import with import numpy as np — NumPy is the foundation for numerical computing in Python. Arrays are faster and more powerful than lists for scientific data.

Array Creation
FunctionDescriptionExampleOutput
np.array() Convert a list (or list of lists) to a NumPy array np.array([1, 2, 3]) array([1, 2, 3])
np.zeros(x) Create array of zeros with shape x np.zeros(3) array([0., 0., 0.])
np.ones(x) Create array of ones with shape x np.ones((2, 3)) array([[1., 1., 1.], [1., 1., 1.]])
np.arange(x, y, z) Array from x to y, stepping by z np.arange(0, 10, 2) array([0, 2, 4, 6, 8])
np.linspace(x, y, z) Array of z evenly spaced values from x to y (inclusive) np.linspace(0, 1, 5) array([0. , 0.25, 0.5 , 0.75, 1. ])

Mathematical Operations
FunctionDescriptionExampleOutput
np.sqrt(array) Square root of each element np.sqrt(np.array([4, 9, 16])) array([2., 3., 4.])
np.exp(array) e^x for each element np.exp(np.array([0, 1])) array([1. , 2.718])
np.log(array) Natural logarithm of each element np.log(np.array([1, np.e])) array([0., 1.])
np.abs(array) Absolute value of each element np.abs(np.array([-3, 4, -1])) array([3, 4, 1])
np.sin(array) Sine of each element (in radians) np.sin(np.array([0, np.pi/2])) array([0., 1.])
np.cos(array) Cosine of each element (in radians) np.cos(np.array([0, np.pi])) array([ 1., -1.])
